# Minimal Python + Pygame Robotics Simulator

Baseline skeleton. Feature work (robot, target, obstacles, arrow-key movement) lands on top as uncommitted changes for review.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python main.py
```

Controls: arrow keys move the robot.
